# 🎓 Calculadora de Média Escolar

## 📌 Sobre o projeto

O projeto **Calculadora de Média Escolar** foi desenvolvido com o objetivo de praticar conceitos fundamentais de lógica de programação e desenvolvimento web.

A aplicação permite que o usuário informe duas notas, calcule automaticamente a média aritmética e verifique a situação do aluno de acordo com a média obtida.

O projeto começou como um algoritmo desenvolvido em Portugol e Visualg e posteriormente foi transformado em uma aplicação web utilizando HTML, CSS e JavaScript.

## 🚀 Funcionalidades

* Inserção de duas notas escolares.
* Cálculo automático da média aritmética.
* Validação de campos obrigatórios.
* Validação de notas entre 0 e 10.
* Classificação automática do resultado.
* Exibição visual de aprovação ou reprovação.

## 📊 Regra de aprovação

A situação do aluno é definida conforme a seguinte regra:

| Média        | Situação  |
| ------------ | --------- |
| 6,00 a 10,00 | Aprovado  |
| 0,00 a 5,99  | Reprovado |

## 💻 Tecnologias utilizadas

* Portugol.
* Visualg (ambiente para execução de algoritmos).
* HTML5 (estrutura da página).
* CSS3 (estilização e layout).
* JavaScript (lógica de programação, validações e cálculo da média).

## 🖥️ Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Localize o arquivo `index.html`.
4. Abra o arquivo em um navegador de sua preferência.
5. Informe as duas notas e clique em **Calcular média**.
